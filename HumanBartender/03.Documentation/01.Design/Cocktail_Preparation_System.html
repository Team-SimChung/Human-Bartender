칵테일 제조 준비 시스템

문서 목적

공통 메뉴에서 칵테일을 확정한 뒤 실제 제조를 시작하기 전까지의 준비 과정을 정의한다. 잔·도구·재료 선택, 레시피 노트, Actual Craft 구성과 제조 시작 요청을 이 문서의 정본으로 사용한다.

상위 문서: 1부 일반 손님 칵테일 제조 루프 기획서

3. 제조 준비 단계

Selected Cocktail을 정답 기준으로 유지하되, 플레이어가 실제로 사용할 잔·도구·재료는 제한하지 않는다. 실제 선택값은 보정 없이 Actual Craft에 저장하고 제조 시작 요청으로 전달한다.

처리 흐름: 잔 선택 → 도구 선택 → 재료 선택 → 레시피 확인 → 진행 조건 검사 → Actual Craft 구성 → 제조 시작 요청

세부 단계플레이어 행동시스템 처리
잔 선택잔 선반에서 잔 1개 선택실제 선택 잔 저장
도구 선택도구 선반에서 제조 도구 선택실제 선택 도구 저장
재료 선택술 선반·냉장고 선반에서 재료 선택실제 선택 재료 저장
제조 준비준비를 마치고 다음 단계로 진행Actual Craft와 제조 요청 구성

3.1 잔 선택

제조 준비 화면에 진입하면 가장 먼저 잔 선반이 표시된다.

플레이어는 제조에 사용할 잔을 직접 선택한다.

3.1.1 기본 규칙

  • 잔은 1개만 선택한다.
  • 정답 잔이 아니어도 선택 가능하다.
  • 선택한 잔을 다시 클릭하면 선택을 해제할 수 있다.
  • 다른 잔을 선택할 경우 기존 선택을 해제하고 새 잔으로 교체한다.
  • 실제 선택한 잔은 Actual Craft에 저장한다.
  • 제조 완료 결과물의 용기에는 실제 선택한 잔을 반영한다.

3.1.2 적용 예시

구분값
정답 잔A
실제 선택 잔B
저장 결과Actual Glass = B
후속 처리B잔으로 제조 진행·잔 불일치는 제조 결과 판정에서 처리

시스템은 실제 선택한 B잔을 정답 잔으로 자동 교체하지 않는다.

3.2 도구 선택

잔 선택 다음에는 도구 선반이 표시된다.

플레이어는 셰이커·믹싱글라스 등 실제 제조에 사용할 도구를 직접 선택한다. 도구 역시 잔과 동일하게 정답을 강제하지 않는다.

3.2.1 기본 규칙

  • 플레이어가 도구를 직접 선택한다.
  • 선택한 도구를 다시 클릭하면 선택을 해제한다.
  • 잘못된 도구를 선택해도 제조 진행을 막지 않는다.
  • 실제 선택한 도구는 Actual Craft에 저장한다.
  • 믹스 기믹의 종류는 Selected Cocktail의 정답 제조법이 아니라, 플레이어가 실제로 선택한 도구를 기준으로 결정한다.
  • 정답 도구와 실제 선택 도구의 일치 여부는 최종 제조 결과 판정에 사용한다.

3.2.2 실제 도구에 따른 기믹

실제 선택 도구실행 기믹
셰이커셰이킹
믹싱글라스스터

따라서 Selected Cocktail의 정답 제조법이 셰이크라고 하더라도 플레이어가 믹싱글라스를 선택했다면 스터 기믹이 실행된다.

3.2.3 적용 예시

구분값
정답 도구·기믹셰이커·셰이킹
실제 선택 도구믹싱글라스
실행 기믹스터
판정도구 불일치 감점

실제 선택 도구를 기준으로 기믹을 실행하며 정답 기믹으로 자동 교정하지 않는다.

3.3 재료 선택

도구 선택 이후에는 재료 선반으로 이동한다.

재료 선반은 크게 다음 순서로 구성한다.

술 선반 → 냉장고 선반

플레이어는 선반을 이동하면서 실제 제조에 사용할 재료를 선택한다.

재료의 배치 화면은 shelf_items.json → shelf_group을 사용한다. liquor는 술 선반, fridge는 냉장고 선반에 배치한다. category는 기믹·재료 분류이므로 선반 위치를 결정하는 데 사용하지 않는다. 데모에서 자동 투입하는 스퀴즈·파우더 재료와 ingredient 이외 항목은 shelf_group: null이다.

3.4 선반 상호작용 및 정보 UI

잔·도구·재료 선반은 동일한 기본 상호작용 규칙을 사용한다.

3.4.1 오브젝트 호버

잔·도구·재료에 마우스를 올리면 해당 오브젝트 주변에 간략 정보 UI를 표시한다.

대상표시 정보
잔이름 / 분류
도구이름 / 분류
술·리큐르이름 / 분류
냉장고 재료이름 / 분류

상세 설명은 표시하지 않는다.

3.4.2 선택 조작

행동결과
미선택 오브젝트 클릭선택
선택된 오브젝트 재클릭선택 해제
하단 트레이의 선택 항목 클릭선택 해제

별도의 + / - 버튼이나 담기 / 빼기 버튼은 사용하지 않는다.

선택된 항목은 하단 트레이에 표시한다.

3.4.3 선반 진열 규칙

선반 종류에 따라 동일 리소스의 진열 방식이 다르다.

선반진열 방식인터랙션 단위
잔 선반동일 잔을 3개 묶음으로 진열 가능묶음 전체
도구 선반동일 도구를 3개 묶음으로 진열 가능묶음 전체
술 선반재료별 병 1개만 진열개별 오브젝트
냉장고 선반동일 재료를 3개 묶음으로 진열 가능묶음 전체

3.4.4 잔·도구·냉장고 묶음 진열

동일한 잔·도구·냉장고 재료가 2개 또는 3개 묶음으로 진열된 경우, 세 오브젝트는 각각 별도의 재고가 아니라 동일한 선택 항목 하나를 표현하는 인터랙션 그룹이다.

세 오브젝트 중 어느 하나에 마우스를 올려도 같은 정보 UI가 표시되고, 어느 하나를 클릭해도 동일 항목이 선택된다.

적용 예시: 냉장고에 진저에일 3병을 진열한 경우 어느 병을 클릭해도 ginger_ale을 선택한다.

선택된 이후 하단 트레이에는 대표 리소스 이미지 1개만 표시한다.

3.4.5 술 선반 개별 진열

술 선반은 3개 묶음 방식을 사용하지 않는다.

각 주류·리큐르 병은 재료별 1개씩만 진열하며, 해당 병 자체가 호버 및 클릭 대상이다.

대표 진열 예시

  • 보드카 1병
  • 데킬라 1병
  • 레드와인 1병
  • 럼 1병
  • 위스키 1병
  • 드라이 버무스 1병

처럼 배치한다.

3.4.6 선택·해제 규칙

행동처리
잔/도구/냉장고의 3개 묶음 중 아무 오브젝트 클릭해당 항목 선택
선택된 묶음 중 아무 오브젝트 재클릭해당 항목 선택 해제
술 선반의 병 클릭해당 재료 선택
선택된 술 병 재클릭해당 재료 선택 해제
하단 트레이 대표 이미지 클릭해당 항목 선택 해제

3.5 선택형 재료와 자동 적용형 재료

모든 재료를 제조 준비 화면에서 직접 선택하는 것은 아니다.

재료는 선택형 재료와 자동 적용형 재료로 구분한다.

구분선반 노출직접 선택실제 재료 결정 기준
주류·리큐르OO플레이어 실제 선택
주스·탄산·기타 액체OO플레이어 실제 선택
스퀴즈 재료XXSelected Cocktail 레시피
파우더 재료XXSelected Cocktail 레시피

3.5.1 선택형 재료

플레이어가 선반에서 직접 선택한다.

기믹에 등장하는 실제 재료도 레시피 정답이 아니라 플레이어가 실제로 선택한 재료를 따른다.

적용 예시: 진피즈의 정답 재료가 진이더라도 럼을 선택했다면 따르기 기믹에는 럼 병이 등장한다.

3.5.2 자동 적용형 재료

cocktails.json → recipe[].auto_apply = true인 재료는 선반에 노출하지 않는다.

플레이어가 직접 선택하거나 조작하지 않으며, auto_applied_ingredients[]에 기록해 제조 시작 요청에 포함한다.

해당 재료의 기믹 생성 여부와 판정 처리는 기믹·판정 문서를 따른다.

3.6 레시피 행동값 전달

제조 준비 화면은 cocktails.json → recipe[].action의 pour와 fill_up을 서로 다른 제조 순서로 표시한다.

두 행동의 실제 조작 재사용 방식, 실행 순서와 점수 처리는 기믹·판정 문서를 따른다.

기믹·판정 정본

칵테일 제조 기믹·등급 계산 시스템

3.7 레시피 노트 및 가이드 기능

제조 준비 화면 좌측 하단에는 레시피 노트 아이콘이 배치된다.

플레이어는 제조 준비 중 언제든지 레시피 노트를 열어 현재 Selected Cocktail의 정답 제조 정보를 확인할 수 있다.

3.7.1 레시피 노트 표시 정보

레시피 노트에는 다음 정보를 표시한다.

항목표시 내용
칵테일 최종 이미지해당 칵테일의 목표 완성 이미지
칵테일명“현재 Selected Cocktail의 이름” + “레시피”
재료선반에서 직접 선택해야 하는 재료만 표시
제조 방법해당 칵테일을 만드는 전체 제조 방법 설명문
목표 잔 / 도구사용해야 하는 잔과 제조 도구

3.7.2 재료 목록 규칙

레시피 노트의 재료 목록에는 선택형 재료만 표시한다.

포함:

  • 주류
  • 리큐르
  • 주스
  • 탄산음료
  • 필업 계열
  • 기타 선반에서 직접 선택하는 액체 재료

제외:

  • 스퀴즈 재료
  • 파우더 재료

예를 들어 진피즈라면 레시피 노트의 재료 목록에는:

  • 진
  • 탄산수

얼음 유무는 목표 잔/도구 정보에 포함하지 않는다.

3.7.3 제조 방법 설명문

모든 칵테일은 개별 제조 방법 설명문을 가진다.

제조 방법은 단순히 Shake, Stir 같은 키워드만 표시하는 것이 아니라, 플레이어가 레시피 노트만 보고도 대략적인 제조 순서를 이해할 수 있는 문장 형태로 작성한다.

설명문 예시

  • 셰이크: 재료를 셰이커에 넣고 잘 흔들어 칵테일 잔에 따른 뒤 제공한다.
  • 스터: 재료를 믹싱글라스에 넣고 저은 뒤 칵테일 잔에 따른다.

스퀴즈·파우더·필업 등이 포함되는 칵테일은 해당 과정도 제조 방법 설명에 포함한다.

즉 제조 방법 텍스트는 칵테일별 고유 데이터로 관리한다.

현행 데이터

제조 방법 설명문은 cocktails.json → recipe_desc.ko·en을 사용한다. 레시피 선택 화면은 현재 언어에 맞는 값을 표시하며 구현 코드에 별도 문장을 작성하지 않는다.

3.7.4 재료 표시

재료 영역에는 해당 칵테일 제조에 필요한 직접 선택 재료와 목표량을 표시한다.

예: 진피즈

  • 진 1.5oz
  • 탄산수 Fill-up

스퀴즈·파우더는 선반에는 노출되지 않지만 레시피 노트의 제조 방법 설명문에는 들어갈 수 있다.

예:

진을 넣고 레몬을 짜 넣은 뒤 설탕을 더해 셰이킹한다. 이후 탄산수로 채운다.

이렇게 하면 플레이어는:

  • 재료 목록 → “내가 선반에서 뭘 골라야 하는지”
  • 제조 방법 → “실제로 어떤 순서로 만드는지”

두 정보를 구분해 표시한다.

레시피 노트의 재료 목록에는 플레이어가 직접 선택하는 재료만 표시한다. 스퀴즈·파우더처럼 자동 적용되는 재료는 목록에서 제외하고 필요한 경우 제조 방법 설명문에서만 안내한다.

대상레시피 목록 표시가이드 점등
정답 잔별도 표기O
정답 도구별도 표기O
술·리큐르OO
냉장고 선택형 재료OO
스퀴즈XX
파우더XX

3.7.5 레시피 노트 닫기

레시피 노트의 우측 상단 X 버튼을 누르거나 ESC 키를 입력하면 노트를 닫는다.

노트를 닫으면 기존 제조 준비 화면으로 돌아간다.

그리고 레시피 노트를 한 번 확인한 뒤 닫은 경우, 현재 Selected Cocktail의 올바른 잔·도구·선택형 재료에 가이드 이펙트를 활성화한다.

3.7.6 가이드 이펙트

이펙트 예시

가이드 이펙트는 정답 오브젝트의 테두리가 일정 간격으로 깜빡이는 방식으로 표시한다.

대상가이드 이펙트
정답 잔O
정답 도구O
정답 술·리큐르O
정답 냉장고 선택형 재료O
스퀴즈 재료X
파우더 재료X

스퀴즈와 파우더는 선반에 오브젝트가 존재하지 않기 때문에 가이드 점등 대상에서 제외한다.

3.7.7 가이드 적용 예시

Selected Cocktail = Gin Fizz

레시피 노트를 확인하고 닫은 뒤:

  • 정답 잔 → 점멸
  • 셰이커 → 점멸
  • 진 → 점멸
  • 탄산수 → 점멸

레몬과 설탕은 선반에 존재하지 않으므로 점멸하지 않는다.

3.7.8 레시피 노트 사용 여부

상태선반 가이드
레시피 노트를 열지 않음가이드 없음
레시피 노트를 확인 후 닫음정답 오브젝트 가이드 활성화

가이드가 표시되더라도 플레이어의 선택을 제한하지 않는다.

즉 플레이어는 점등된 정답 오브젝트 대신 다른 잔·도구·재료를 선택할 수 있으며, 실제 선택값은 그대로 Actual Craft에 기록한다.

3.8 제조 준비 완료

플레이어는 제조 준비 단계에서 정답 선택을 모두 완료하지 않아도 기믹 플레이로 넘어갈 수 있다.

기믹 진입 방식은 다음 두 가지로 구분한다.

  • 자동 준비 완료 안내
  • 수동 진행

3.8.1 자동 준비 완료 안내

플레이어가 현재 Selected Cocktail의 올바른 제조 준비 항목을 모두 선택하면 시스템이 이를 자동으로 감지한다.

자동 준비 완료 판정 대상은 다음과 같다.

판정 대상조건
잔정답 잔 선택
도구정답 도구 선택
선택형 재료해당 칵테일에 필요한 선택형 정답 재료를 모두 선택
스퀴즈판정 제외
파우더판정 제외

스퀴즈와 파우더는 선반에서 직접 선택하지 않는 자동 적용형 재료이므로 제조 준비 완료 판정에 포함하지 않는다.

조건을 모두 만족하면 별도의 조작 없이 자동으로 준비 완료 안내 팝업을 표시한다.

안내 문구: 모든 재료를 선택하셨습니다. 다음 단계로 진행하십시오.

플레이어가 확인 버튼을 누르면 제조 준비를 종료하고 기믹 플레이 단계로 이동한다.

자동 준비 완료 안내는 정석 제조 준비를 마친 플레이어에게 다음 단계로 넘어갈 수 있음을 알려주는 편의 기능이다.

3.8.2 수동 진행과 다음 버튼

정답 준비를 완성하지 않아도 잔 1개와 선택형 재료 1종 이상을 선택하면 다음 버튼을 활성화한다. 도구 선택과 잔·재료의 정답 여부는 활성 조건에 포함하지 않는다.

아래 표는 조합별 버튼 상태다.

선택 상태다음 버튼
아무것도 선택하지 않음비활성화
잔만 선택비활성화
도구만 선택비활성화
재료만 선택비활성화
잔 + 도구비활성화
도구 + 재료비활성화
잔 + 재료 1종 이상활성화
잔 + 틀린 재료 1종 이상활성화
잔 + 일부 재료만 선택활성화
잔 + 여러 재료 선택활성화
잔 + 재료 + 도구만 미선택활성화
정답 잔 + 정답 도구 + 정답 재료 전부활성화 + 자동 준비 완료 안내

즉 잔이 없는 상태에서는 어떤 조합이더라도 기믹 플레이로 넘어갈 수 없다.

3.8.3 도구 미선택 상태

도구는 수동 기믹 진입의 필수 조건이 아니다.

따라서 잔과 선택형 재료를 선택했다면, 도구를 선택하지 않은 상태에서도 기믹 플레이로 넘어갈 수 있다.

선택 상태진행 결과
잔 O·진 O·탄산수 O·도구 X수동 진행 허용
도구와 무관한 Open·Pour·Squeeze·Powder·Fill-up실제 선택값에 따라 생성
도구가 필요한 Shake·Stir생성하지 않음

도구 미선택 여부는 이후 제조 결과 판정에서 실패 요소로 처리한다.

3.8.4 재료 선택 수와 실행 순서

플레이어가 선택할 수 있는 재료 수를 Selected Cocktail의 정답 재료 수에 맞춰 제한하지 않는다.

예를 들어 진피즈의 선택형 정답 재료가 진 + 탄산수라고 하더라도 플레이어는 다음과 같이 자유롭게 선택할 수 있다.

  • 진만 선택
  • 탄산수만 선택
  • 럼만 선택
  • 크랜베리주스만 선택
  • 럼 + 크랜베리주스
  • 크랜베리주스 + 파인애플주스
  • 정답보다 많은 종류의 재료 선택

단, 모든 경우 잔은 반드시 선택되어 있어야 한다.

재료의 누락이나 불필요한 재료 추가는 제조 준비 단계에서 차단하지 않고, 실제 제조 과정과 최종 결과 판정에 반영한다.

동일한 기믹 역할을 가진 재료를 여러 개 선택한 경우에는 플레이어가 해당 재료를 선택한 순서대로 기믹에 등장한다.

예를 들어 플레이어가 다음 순서로 선택했다고 가정한다.

  1. 크랜베리주스 — Fill-up
  1. 파인애플주스 — Fill-up

실제 필업 순서는:

필업(크랜베리주스) → 필업(파인애플주스)

가 된다.

반대로 파인애플주스를 먼저 선택했다면 실행 순서도 반대가 된다.

서로 다른 기믹 종류 사이에서는 재료 선택 순서보다 기믹 고정 우선순위가 우선한다.

순서 예시: 크랜베리주스(Fill-up)를 럼(Pour)보다 먼저 선택해도 실제 제조에서는 따르기(럼) → … → 필업(크랜베리주스) 순서로 실행한다.

3.8.5 핵심 원칙

핵심 원칙

정답 준비를 모두 마치면 자동 안내를 표시한다. 정답을 완성하지 않아도 잔과 선택형 재료 1종 이상이 있으면 수동 진행을 허용한다. 선택한 재료의 수와 종류는 제한하지 않으며 실제 선택 결과를 Actual Craft에 기록한다.

3.9 Actual Craft 구성

플레이어가 제조 준비 단계를 종료하고 기믹 플레이로 진입하면, 시스템은 플레이어가 실제로 선택한 제조 정보를 Actual Craft로 저장한다.

Actual Craft는 Selected Cocktail의 정답 레시피와 별개로, 플레이어가 실제로 무엇을 선택했는지 기록하는 데이터다.

이 정보는 제조 시작 요청의 입력값으로 기믹·판정 시스템에 전달한다.

3.9.1 저장 항목

데이터내용
Actual Glass플레이어가 실제로 선택한 잔
Actual Tool플레이어가 실제로 선택한 도구
Actual Ingredients플레이어가 실제로 선택한 재료와 선택 순서
Auto Applied Ingredientsrecipe[].auto_apply = true인 스퀴즈·파우더 재료
Mixing Ice·Serving Icecocktails.json → mixing_ice·serving_ice를 기준으로 별도 저장하는 얼음 상태
Actual Mix실제 선택 도구에 따라 결정되는 믹스 방식

3.9.2 Actual Glass

Actual Glass에는 플레이어가 제조 준비 단계에서 실제로 선택한 잔을 저장한다.

정답 잔인지 여부와 관계없이 실제 선택값을 그대로 기록한다.

저장 예시: Target Glass가 올드패션 글라스이고 실제로 칵테일 글라스를 선택했다면 Actual Glass = 칵테일 글라스로 저장한다.

잔은 수동 기믹 진입의 필수 조건이므로, 기믹 플레이 진입 시 Actual Glass는 반드시 존재한다.

3.9.3 Actual Tool

Actual Tool에는 플레이어가 실제로 선택한 제조 도구를 저장한다.

정답 도구가 아니더라도 선택한 도구를 그대로 기록한다.

도구는 수동 기믹 진입의 필수 조건이 아니므로 선택하지 않은 상태도 허용한다.

예:

상태Actual Tool
셰이커 선택셰이커
믹싱 글라스 선택믹싱 글라스
도구 미선택없음

Actual Tool은 이후 믹스 기믹을 결정하는 기준으로 사용한다.

  • 셰이커 → 셰이킹
  • 믹싱 글라스 → 스터
  • 도구 미선택 → 믹스 기믹 생성 안 함

즉 Selected Cocktail의 정답 믹스 방식보다 플레이어가 실제로 선택한 도구를 우선한다.

3.9.4 Actual Ingredients

Actual Ingredients에는 플레이어가 선반에서 직접 선택한 선택형 재료를 저장한다.

정답 여부와 관계없이 실제 선택한 재료를 모두 기록한다.

예를 들어 메뉴 리스트에서 진피즈를 선택한 상태에서 플레이어가

  1. 럼
  1. 크랜베리주스
  1. 파인애플주스

를 선택했다면:

Actual Ingredients = 럼, 크랜베리주스, 파인애플주스

로 저장한다.

Selected Cocktail의 정답 재료와 다른 재료를 선택하거나, 일부 재료를 누락하거나, 정답보다 많은 재료를 선택한 경우에도 실제 선택 상태를 그대로 보존한다.

3.9.5 Ingredient Selection Order

같은 기믹 역할을 가진 재료가 여러 개 선택될 수 있으므로 재료의 선택 순서도 함께 저장한다.

선택 순서 예시: 크랜베리주스 다음 파인애플주스를 선택했다면 해당 순서를 유지한다.

이 순서는 제조 시작 요청에 포함해 기믹 시스템으로 전달한다.

선택 순서를 실제 기믹 순서로 변환하는 규칙은 기믹·판정 문서에서 관리한다.

3.9.6 자동 적용 재료

스퀴즈·파우더는 Selected Cocktail의 레시피를 기준으로 자동 적용한다.

recipe[].auto_apply = true인 재료는 Auto Applied Ingredients에 재료 ID·수량·단위·행동을 기록한다.

얼음은 재료 배열에 합치지 않고 cocktails.json → mixing_ice·serving_ice 값을 별도 필드로 전달한다. 데모에서는 두 항목 모두 플레이어가 직접 선택하지 않는다.

3.9.7 Actual Mix

Actual Mix는 Selected Cocktail의 정답 제조법이 아니라 Actual Tool을 기준으로 결정한다.

Actual ToolActual Mix
셰이커Shake
믹싱 글라스Stir
도구 미선택없음

예를 들어 Selected Cocktail의 정답 제조법이 셰이크라고 하더라도 플레이어가 믹싱 글라스를 선택했다면:

Actual Tool = 믹싱 글라스

Actual Mix = Stir

로 처리한다.

반대로 도구를 선택하지 않았다면 Actual Mix는 생성하지 않는다.

3.9.8 핵심 원칙

  • Selected Cocktail: 플레이어가 만들기로 선택한 칵테일의 정답 기준.
  • Actual Craft: 플레이어가 실제로 선택하고 수행한 제조 상태.

두 데이터는 서로 별도로 유지한다.

따라서 루프 시스템은 플레이어의 오선택을 정답값으로 보정하지 않고 실제 선택 상태를 그대로 외부 기믹·판정 시스템에 전달한다.

3.10 제조 시작 요청

제조 준비가 끝나면 루프 시스템은 Selected Cocktail과 Actual Craft를 하나의 제조 요청으로 묶어 기믹 시스템에 전달한다.

전달 항목설명
selected_cocktail_id플레이어가 제조 대상으로 확정한 칵테일 ID
actual_glass_id실제로 선택한 잔 ID
actual_tool_id실제로 선택한 도구 ID
actual_ingredients[]플레이어가 선택한 재료와 선택 순서
auto_applied_ingredients[]레시피에 따라 자동 적용되는 스퀴즈·파우더 재료
mixing_ice·serving_ice레시피에서 읽은 얼음 상태
guest_id·order_id전달하지 않음·서빙 대상 코스터가 확정될 때 연결

루프 시스템은 각 요청에 고유한 요청 ID를 부여하고, 같은 요청이 중복 실행되지 않도록 완료 여부를 저장한다.

기믹 큐의 생성 순서, 각 기믹의 조작 규칙, 성공·실패 처리와 종료 조건은 이 문서에서 정의하지 않는다. 다음 문서를 정본으로 사용한다.

칵테일 제조 기믹·등급 계산 시스템

3.11.1 제조 준비 화면

UI 요소데이터 경로표시·동작

3.12 확인된 데이터 예시

3.12.1 칵테일 데이터 발췌

아래 예시는 구조 설명용 발췌다. 코드 블록 내부의 문법 색상은 Notion 테마가 결정하며 의미 색상은 본문의 데이터 경로 표기를 따른다.

루프 시스템은 cocktails.json에서 메뉴 표시, 준비 화면과 외부 시스템 요청에 필요한 필드만 사용한다. 아래는 해당 필드의 발췌 예시다.

{
  "id": "gin_fizz",
  "name": {
    "ko": "진피즈",
    "en": "Gin Fizz"
  },
  "status": "confirmed",
  "glass": "long_drink",
  "mix": "shake",
  "unlock_day": 0,
  "time_limit_sec": 52,
  "recipe": [
    {
      "action": "pour",
      "ingredient": "gin",
      "qty": 1.5,
      "unit": "oz",
      "auto_apply": false
    },
    {
      "action": "squeeze",
      "ingredient": "lemon",
      "qty": 0.5,
      "unit": "oz",
      "auto_apply": true
    },
    {
      "action": "powder",
      "ingredient": "sugar",
      "qty": 1,
      "unit": "tsp",
      "auto_apply": true
    },
    {
      "action": "fill_up",
      "ingredient": "soda_water",
      "qty": 3,
      "unit": "oz",
      "auto_apply": false
    }
  ],
  "sprite": "Finished_GinFizz",
  "serve_sprite": "Serve_GinFizz"
}
  • auto_apply = false인 재료는 제조 준비 화면에서 플레이어가 직접 선택한다.
  • auto_apply = true인 재료는 선반 선택 대상에서 제외하고 제조 요청의 auto_applied_ingredients[]에 포함한다.
  • is_core·scored 등 판정 전용 필드의 해석은 기믹·판정 문서를 따른다.

3.12.2 선반 데이터 발췌

{
  "id": "soda_water",
  "kind": "ingredient",
  "name": {
    "ko": "탄산수",
    "en": "Carbonated Water"
  },
  "color": "245,250,255",
  "unlock_day": 0,
  "default_action": "fill_up",
  "default_target_qty": 3.0,
  "default_target_unit": "oz"
}

루프 시스템은 플레이어가 선택한 선반 항목의 ID와 관련 필드를 Actual Craft에 기록해 외부 시스템으로 전달한다. 레시피 외 재료의 행동 결정과 판정 처리는 기믹·판정 문서를 따른다.

3.13 오류·예외 처리와 검증

3.13.1 오류·예외 처리

상황처리
잔 미선택 또는 선택형 재료 0개다음 버튼 비활성화·제조 요청 생성 금지
선택한 선반 ID가 데이터에 없음해당 선택 제거·오류 기록·임의 대체 금지
도구 미선택진행 허용·Actual Tool과 Actual Mix를 없음으로 저장·믹스 기믹 미생성
제조 시작 입력 연속 발생첫 요청만 생성·동일 request_id 재사용 금지
레시피 노트 재개방현재 선택 상태와 가이드 활성 상태 유지

3.13.2 구현 완료 기준

  • 잔과 선택형 재료 1종 이상을 선택해야 다음 버튼이 활성화된다.
  • 오선택과 선택 순서가 자동 보정 없이 Actual Craft에 그대로 저장된다.
  • Actual Tool이 없으면 믹스 기믹을 생성하지 않는다.
  • auto_apply 재료와 얼음 필드가 분리되어 제조 요청에 포함된다.
  • 제조 요청에는 guest_id와 order_id가 포함되지 않는다.
