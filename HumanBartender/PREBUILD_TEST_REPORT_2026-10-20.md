# 빌드 전 자체 테스트 — 2026-10-20

Unity 6000.3.14f1 / Windows / Direct3D 11에서 검사했다. 열려 있던 작업 프로젝트와 실제 저장 데이터를 보호하기 위해 프로젝트·캐시를 별도로 복사하고, 테스트 복사본의 회사명·제품명을 변경했다. 실제 배포용 EXE 빌드와 업로드는 하지 않았다.

사용자의 추가 설명에 따라 테스트 코드는 보존하고, 정상 플레이와 빌드에서 테스트 설정이 작동하지 않도록 정리했다. 따르기의 실제 출수량과 수량별 배율은 변경하지 않았다.

## 테스트 자체의 오류 수정

- 선택지 테스트 4건이 삭제·교체된 `outside ChoicePanel.prefab`의 옛 경로를 참조했다. 남아 있는 대화 선택지 프리팹 검사는 유지하고, 폐기된 외부 UI에 대한 중복 파라미터만 제거했다. 현재 외부 선택지는 실제 CSV·입력·금액 조건 테스트로 확인했다.
- 거품 표면 테스트는 액체 줄기의 밝은 탄산 기포까지 거품의 최고점으로 셌다. 거품 경계만 검사하는 합성 단계에서 탄산 표시를 제외했다. 이 테스트가 측정한 인접 열 높이 차이는 81px에서 6px로 정상화됐다(허용 7px). 액체 셰이더나 출수량은 수정하지 않았다.
- 외곽선 단독 실행 테스트는 모든 상호작용 대상에 SpriteRenderer가 있다고 가정했다. 논리 전용 대상은 제외하고 렌더러가 있는 대상의 외곽선을 검사하도록 수정했다. 비활성화한 테스트 NPC는 해당 명시적 테스트 안에서만 켠다.
- 코스터 실제 입력 테스트 실패 시 클릭 좌표·해상도·UI 적중 목록이 남도록 진단 메시지를 보강했다.

## 남아 있는 콘텐츠 확인 사항과 검증 범위

- 제조 데이터 경고 2건은 `blue_hawaii`, `june_bug`의 파인애플 주스가 레시피에서는 FillUp, 재료 기본 동작에서는 Pour인 점이다. 레시피 의도일 수 있어 양·동작 데이터를 임의 변경하지 않았다.
- 새 게임의 미연결 연출 `luna-dream`과 일부 캐릭터 Intro 키는 기존 대체·건너뛰기 경로로 진행한다. 해당 경고와 원본 자산이 없는 이전 더미·레거시 GUID 참조는 별도 로그에 남겼다. 이번 검사는 새 연출 자산 제작이나 모든 대사의 완주 검증을 포함하지 않는다.
- 배포용 Addressables 번들·EXE 생성 및 실제 배포 환경 검사는 최종 빌드 단계에서 필요하다.

원본 NUnit 결과 XML, 실행 로그 및 정적 자산 검사 자료는 `.utmp/prebuild-qa-2026-10-20/`에 보관한다. 테스트 전부터 있던 상위 `README.md` 수정은 건드리지 않았다.
