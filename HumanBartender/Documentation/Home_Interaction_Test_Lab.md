# Home 상호작용 테스트 환경

Unity 메뉴 **Tools > Human Bartender > Tests > Home Interaction Lab**에서 엽니다.
게임 빌드에 포함되지 않는 에디터 전용 도구입니다. 별도 연습 씬을 만들지 않고 저장된 실제 `Home` 씬과 CSV, 주입 서비스, 입력, 카메라를 사용합니다.

## 시작과 반복

1. 편집 중인 씬 변경을 먼저 저장합니다. 외부 변경 확인 창이 있다면 편집 내용과 디스크 변경을 확인한 뒤 정리합니다.
2. Play 모드가 꺼진 상태에서 창의 **준비할 상황**을 고릅니다.
3. **선택 상황으로 테스트 시작**을 누릅니다. Main의 실제 부트스트랩을 거쳐 Home으로 들어가고 대상 위치로 이동합니다. 전체 오프닝 상황에서는 위치를 옮기지 않습니다.
4. 대상별 **이동 후 상호작용 실행** 또는 Game 창의 기존 상호작용 입력으로 확인합니다. TV 자동 방송은 **접근하여 자동 방송 확인**으로 확인합니다.
5. 창의 **대사 진행 / 선택 확정**, **이전 선택 / 다음 선택**으로 대사와 선택지를 조작할 수 있습니다. 오프닝 안내는 Game 창의 안내 키로 진행합니다.
6. **선택 상황 다시 불러오기**로 완료 기록과 일회성 대화, NPC 배치까지 새로 준비합니다. 현관으로 OutSide에 나갔거나 엔딩으로 넘어가도 이 버튼으로 Home에 돌아올 수 있습니다.
7. **테스트 종료** 또는 Unity의 Play 종료로 끝냅니다. 원래 Play 시작 씬 설정과 게임 상태·TimeScale을 복원합니다.

취침 중에는 진행을 끝내고 상황을 다시 불러옵니다. 대화·메뉴는 **상호작용 취소**로 닫을 수 있습니다. 준비 중에는 다른 준비 작업을 중복 실행하지 않습니다.

## 제공하는 16개 상황

| 상황 | 확인할 내용 |
| --- | --- |
| 0일차 · 오프닝부터 | 도입과 조작 안내, 첫 현관·TV |
| 0일차 · 출근 / TV | 현관 이동, TV 최초 시청 |
| 1일차 · TV 자동 방송 | TV 범위 진입에 따른 주변 자동 대화 |
| 2일차 · 출근 / TV | 당일 TV, 현관 이동 |
| 3일차 · 출근 / TV | 마지막 날 TV, 현관 이동 |
| 0일차 · 테라스와 다음 날 | night0, 테라스 이동, 다음 날 실내 복귀 |
| 1일차 · 작업장 → 테라스 | workshop → night1 순서 |
| 1일차 · 테라스만 반복 | 작업장을 건너뛴 Terrace 로컬 X -1.8 → 0 진입 |
| 2일차 · 조니 기억 획득 | 재료는 보유하고 기억은 미확인인 상태에서 night2 실행 |
| 2일차 · 취침 조건 부족 | 야간 대화 완료 후 재료·기억 부족에 따른 취침 거부 |
| 2일차 · 조건 충족 / 다음 날 | 조건을 충족한 수면과 3일차 진입 |
| 3일차 · 마지막 테라스 / 생존 엔딩 | ending과 삼호 생존 크레딧 |
| 3일차 · 마지막 테라스 / 사망 엔딩 | ending과 삼호 사망 크레딧 |
| 부비 · 쓰다듬기 / 취소 | 입양한 부비의 반복 상호작용 |
| 부비 · 입양 후 첫 취침 | neighborhood-rest, 크리스 등장·퇴장, 부비 반응 |
| 소파 · 저장 / 취소 / 수면 | 슬롯 선택·페이지·덮어쓰기·저장 결과·취소·수면 |

TV의 **처음 보는 상태로 / 이미 본 상태로** 버튼으로 현재 날짜의 최초 시청과 재시청 선택지를 바꿉니다. 1일차 출근은 자동 방송이 우선하므로 1일차 수동 TV 재시청은 퇴근 상황에서 확인합니다.

창에는 비활성 대상을 포함한 Home의 전체 대상과 현재 사용 가능 여부가 표시됩니다. 실제 등장·대화 조건은 우회하지 않습니다.

## 데이터와 저장

- 시작 상황마다 테스트 플레이어는 돈 1000, 스킬 0으로 준비되며 호감도·진행 플래그를 초기화한 뒤 필요한 조건만 적용합니다.
- 원본 PlayerDataSO를 복사해 DI에 주입합니다. 실제 플레이어 SO의 진행 값을 수정하지 않습니다.
- 저장 메뉴도 실제 SaveManager를 사용합니다. 경로는 프로젝트 안의 `Library/HomeInteractionTests/ManualSaves/<세션ID>/`입니다. 일반 `manual-saves` 슬롯은 읽거나 쓰지 않습니다.
- 같은 테스트 세션에서는 저장 파일이 유지되어 슬롯 이동과 덮어쓰기를 확인할 수 있습니다. 새 테스트 세션은 별도 폴더를 사용합니다.
- **테스트 저장 폴더 열기**에서 생성된 슬롯 JSON을 확인할 수 있습니다. 종료 시 테스트 저장 파일을 자동 삭제하지 않습니다.
- Play 도중 스크립트를 다시 컴파일하면 테스트를 종료합니다. 컴파일 완료 후 창에서 다시 시작합니다.

## 현재 씬의 범위

실제로 연결된 대상은 현관 `home_exit_door`, 소파 `home_sofa`, TV `home_tv`, 부비 `neighborhood-homeCat`입니다.

`home-bed`, `home-wardrobe`, `home-wardrobe-pressed`는 CSV 대본만 있고 현재 Home 씬에 상호작용 대상이 없습니다. `home_terrace_door`도 예약 위치입니다. 테라스의 날짜별 이야기는 소파 수면으로 검증합니다.

## 검증

Test Runner의 EditMode에서 `HomeInteractionTestEnvironmentTests`를 실행하면 상황 초기화, 실제 씬 대상의 전체 포함과 접근 조건, CSV 야간 대본, 2일차 취침 조건을 검사합니다. 테라스 이동 자체는 `HomeTerracePresentationTests`로 검사합니다.

실제 대사·그림·사운드·카메라는 위 테스트 창에서 수동 확인합니다. Unity가 열려 있을 때 별도 배치 테스트 프로세스를 실행하지 않습니다.
