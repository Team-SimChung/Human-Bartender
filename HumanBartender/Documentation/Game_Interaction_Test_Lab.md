# 게임 상호작용 지점 테스트

Unity 메뉴 **Tools > Human Bartender > Tests > Game Interaction Lab**에서 엽니다. 기존 기믹 테스트와 Home 테스트 창의 위쪽 버튼으로도 이동할 수 있습니다.

**홈 상호작용 프리셋 / 외부 상호작용 프리셋 / 바 내부 대사 선택**으로 상세 도구를 엽니다. 외부 프리셋은 홈과 같은 창에서 21개 상황을 제공합니다. 불량배·삼호·시BAR·부비·수리공·경비·보스·문·라디오·엘리베이터의 날짜와 필요한 진행 플래그를 준비합니다. 바 내부는 [대사 선택 테스트](Bar_Dialogue_Test_Lab.md)에서 실제 대사 본문 한 줄을 골라 시작합니다.

## 지점에서 바로 시작

1. 작업 중인 씬을 저장하고 Play 모드를 종료합니다.
2. 시작 씬 **Home / OutSide**, **0~3일차**, **출근 / 퇴근**, 시작 지점을 고릅니다.
3. **선택 지점으로 테스트 시작**을 누릅니다. Main 부트스트랩과 실제 게임 진행 서비스를 통해 별도 플레이어·저장 경로를 준비하고 선택한 씬과 지점으로 이동합니다.
4. 현재 씬의 지점 목록에서 **이동 후 상호작용 실행**을 누르거나 Game 창의 실제 입력으로 확인합니다. 자동 사건과 주변 대화는 **접근하여 자동 실행 확인**으로 접근합니다.
5. **대사 진행 / 선택 확정**, **이전 선택**, **다음 선택**, **상호작용 취소**를 사용할 수 있습니다. 취침 등 취소를 허용하지 않는 연출은 완료 후 반복합니다.
6. 다른 시작 조건·지점을 고르고 **조건 초기화 후 선택 지점으로 이동**을 누르면 일회성 기록을 포함한 진행 상태를 다시 준비합니다. 문을 통해 다른 씬으로 이동해도 새 씬의 대상 목록을 표시합니다.

목록은 저장된 씬의 `WorldInteractionTarget`을 비활성 자식까지 읽습니다. 새 대상을 저장한 뒤 편집 모드에서 **씬·CSV 목록 갱신**을 누르면 반영됩니다. 대상이 배치되지 않은 CSV 대본이나 예약 위치는 실행 지점으로 만들지 않습니다. Play 씬의 제조 기믹·칵테일은 같은 창의 **기믹 / 칵테일 테스트**에서 기존 도구로 확인합니다.

## 조건과 표시

날짜·출퇴근·등장 조건·상호작용 조건·완료 플래그는 실제 게임 판정을 따릅니다. 사용할 수 없는 지점도 목록에 남으며, 해당 CSV 정의와 대본 조건을 함께 표시합니다. 강제로 조건을 무시해서 실행하지 않습니다.

**테스트 진행 조건**에서 소지금을 적용하고, **플래그 수정**에서 CSV의 `flag.` 조건과 현재 플레이어의 플래그를 검색해 켜고 끌 수 있습니다. 직접 입력도 가능합니다. 대화·연출·준비 중에는 변경을 잠급니다. 변경은 테스트 플레이어에만 적용하며, 상황을 다시 불러오면 초기화됩니다. 완료 플래그를 꺼도 같은 씬의 일회성 기록은 남을 수 있으므로 처음부터 반복하려면 상황을 다시 불러옵니다.

지점 테스트에서는 0일차 거리의 첫 출근 강제 보행과 바 주변 이동 경계를 생략합니다. 씬을 준비하는 동안에는 자동 사건 감지를 잠시 멈추고, 선택 지점 배치를 마친 뒤 실제 감지를 재개합니다. 홈 전체 오프닝·테라스·수면의 세부 프리셋은 기존 **홈 세부 시나리오**에서 확인합니다.

## 월드 대본부터 시작

지점으로 이동해도 첫 메뉴·앞 대사를 반복해야 하는 내부 분기를 확인할 때 사용합니다.

1. 창 위쪽의 **월드 대본부터**를 고릅니다. Home/OutSide의 내부 분기 대본을 직접 실행하는 고급 기능입니다. 바 내부의 대사 한 줄 선택은 **바 내부 대사 선택**을 사용합니다.
2. Home / OutSide, 일차·출퇴근을 고르고 **대본 검색 (ID / 제목)**에서 시작할 대본을 찾습니다. `home-wardrobe-pressed`, `shiba-allowance`, `neighborhood-bossPayRepeat`, `night2`처럼 지점 목록에 직접 나오지 않는 내부 대본도 포함합니다.
3. **연출을 사용할 지점**에서 원래 그 대본을 호출하는 지점을 고릅니다. 시BAR 분기는 시BAR, 부비 분기는 해당 부비, 테라스 대본은 소파를 사용합니다. 이 지점의 NPC·화자·컷씬·장소 이동 연결을 사용합니다.
4. **선택 대본부터 테스트 시작** 또는 **조건 초기화 후 대본부터 시작**을 누릅니다. 해당 대본의 첫 단계에서 시작하고 뒤의 선택·명령·연출은 실제 실행기를 따릅니다. 테라스 대본은 기존 테라스 진입·카메라를 사용한 뒤 실내로 복귀합니다.
5. NPC가 아직 등장하지 않는 조건이라면 테스트를 시작한 상태에서 날짜·플래그 등 필요한 조건을 준비한 뒤 **현재 조건으로 선택 대본 실행 (플래그 유지)**을 누릅니다. 같은 버튼으로 조건을 유지하고 반복할 수 있습니다.

직접 시작은 대본의 날짜·출퇴근·진입 조건과 상호작용 지점의 첫 메뉴를 생략합니다. 각 단계와 선택지의 `when`, 효과, NPC 동작, 컷씬, 완료 플래그는 실제 처리합니다. 지점과 NPC 자체의 존재·사용 가능 여부는 필요합니다. 생략한 앞 대사가 만든 플래그·NPC 상태를 복원하거나 대사 중간의 임의 단계부터 실행하는 기능은 포함하지 않습니다.

직접 대본 모드에서는 주변 자동 사건·접근 대화 감지를 멈춥니다. 재생 중 대사·선택·취소 조작은 계속 사용할 수 있으며, 재생을 끝내고 **접근 자동 감지 재개**를 누르면 일반 감지로 돌아갑니다. **상호작용 지점부터** 모드로 상황을 다시 불러와도 복원됩니다. 이 모드는 개별 대본 확인용이며 소파의 전체 취침·다음 날 진행은 원래 소파 상호작용으로 확인합니다.

## 데이터와 종료

기존 Home 테스트 세션을 공유합니다. 플레이어 SO는 복제하고 저장은 `Library/HomeInteractionTests/ManualSaves/<실행 ID>`로 분리합니다. 종료하면 시작 씬·날짜·게임 상태·TimeScale을 복원합니다. 저장된 게임 씬과 원본 플레이어 에셋은 수정하지 않습니다. 다른 일반 Play 세션이나 기믹 테스트와 동시에 시작할 수 없습니다.

`WorldInteractionTestEnvironmentTests`는 씬 목록 보존, 지점 ID 중복, 시작 조건의 왕복과 진행 초기화, 내부 분기 대본의 목록과 컴파일된 명령을 검증합니다. 수동 확인에서는 Home/OutSide를 각각 출근·퇴근으로 시작하고 문 이동, 비활성 대상, 자동 사건, 플래그 변경, 반복 실행을 확인합니다. 대본 직접 시작은 시BAR·부비 등의 내부 분기와 테라스, 취소·반복·자동 감지 재개를 확인합니다.
