# 기믹 바로 플레이

Unity 메뉴 **Tools > Human Bartender > Tests > Gimmick Play Lab**에서 엽니다.
홈·거리의 상호작용 지점은 창 위쪽의 **게임 내 상호작용 지점 테스트 열기** 또는 [게임 상호작용 지점 테스트](Game_Interaction_Test_Lab.md)에서 확인합니다.

## 간단 테스트 · 4종 연속

창 위쪽의 **간단 테스트 · 4종 연속** 버튼을 누르면 **병따기 → 따르기 → 스터 → 셰이킹**을 한 번씩 이어서 플레이합니다. 레시피·재료·잔·도구·목표량은 실제 CSV에서 자동 선택하므로 아래 선택 칸을 조작할 필요가 없습니다.

기믹을 완료하거나 마치기 버튼을 누르면 다음 기믹이 시작됩니다. **현재 플레이 중단**은 남은 순서도 함께 멈춥니다. 네 기믹을 모두 마치면 **간단 테스트 결과**에서 각각의 자동 선택 예시와 시간·수량·성공·실패 결과를 확인할 수 있습니다. 같은 버튼으로 다시 실행할 수 있고, 이 툴로 Play 모드를 시작한 상태에서도 준비 완료·대기 중이면 바로 실행됩니다.

각 기믹은 해당 예시의 실제 제조 설정과 새 시계·기록을 사용합니다.

창 위쪽의 **기믹 하나 / 칵테일 한 잔**으로 실행 모드를 바꿉니다.

## 칵테일 한 잔 만들기

1. **칵테일 한 잔**에서 **만들 칵테일**을 고릅니다. 잔·도구·제한 시간과 전체 제조 순서를 확인할 수 있습니다.
2. **선택 칵테일 제조 시작**을 누릅니다. 레시피의 정답 잔·도구·재료를 자동 준비한 뒤, 실제 제조 큐의 모든 단계를 순서대로 플레이합니다.
3. 각 기믹을 완료하거나 실제 화면의 마치기 버튼을 누르면 다음 단계로 넘어갑니다. 정량 추가는 자동으로 기록하고, 자동 투입 재료도 제조 기록에 반영합니다.
4. 모든 단계가 끝나면 **칵테일 제조 결과**에 전체 조작 시간, 단계별 결과, 실제 `CraftJudge`의 제조 점수·등급이 표시됩니다.
5. **선택 칵테일 다시 만들기**로 같은 칵테일을 반복하거나 다른 칵테일을 선택합니다. **현재 플레이 중단**은 진행 중인 한 잔 전체를 중단합니다.

기믹이 바뀌어도 한 잔의 시계와 제조 기록은 이어집니다. 다시 만들 때는 새 시계와 기록으로 시작합니다.

## 기믹 하나 플레이

1. **기믹**에서 병따기·따르기·셰이크·스터·필업을 고릅니다.
2. **레시피 / 재료**에서 확인할 칵테일과 재료를 고릅니다. 목표량·잔·도구는 실제 CSV의 정답 구성을 사용합니다.
3. **선택 기믹으로 테스트 시작**을 누릅니다. 저장 여부를 묻는 창이 있으면 편집 중인 씬을 정리한 뒤 진행합니다.
4. Main의 실제 부트스트랩과 CSV 로딩을 거쳐 Play 씬에 들어가며, 제조 준비·영업 대사·튜토리얼 없이 선택한 기믹 하나가 시작됩니다. Game 창에 포커스를 두고 기존 키·마우스로 조작합니다.
5. 완료하면 창의 **최근 결과**에서 조작 시간과 실제량·목표량 또는 성공·실패 횟수를 확인합니다. 수량 기믹은 실제 화면의 마치기 버튼으로 끝냅니다.
6. **선택 기믹 다시 플레이**로 반복하거나 다른 기믹·재료를 고른 뒤 같은 버튼으로 실행합니다. 진행 중에는 **현재 플레이 중단**으로 정리한 다음 다시 실행합니다.
7. **테스트 종료** 또는 Unity의 Play 종료로 마칩니다.

실제 `GimmickRunner`, 기믹 프리팹, HUD, 카메라와 `CraftGimmickInputRouter`를 사용합니다. 별도 테스트 씬이나 UI를 만들지 않습니다. Play 씬 인스턴스의 `PlayPhaseController`만 Start 전에 비활성화해 하루 진행을 시작하지 않습니다. 씬·프리팹 에셋의 설정은 바꾸지 않습니다.

필업은 실제 게임과 같이 따르기 프리팹을 재사용합니다. 자동 투입되는 재료와 정량 추가는 기믹 단독 목록에서 제외하지만, 칵테일 한 잔의 제조 기록에는 포함합니다. CSV가 바뀌면 Play 종료 후 **CSV 목록 새로고침**을 누릅니다. 실행 전에 선택한 기믹 또는 칵테일 전체에 필요한 프리팹과 Play 실행기의 연결을 확인합니다.

플레이어 데이터는 복사본을 DI에 연결하고, 저장 서비스 경로는 프로젝트의 `Library/GimmickPlayTests/ManualSaves/<세션ID>/`로 분리합니다. 종료할 때 이전 Play 시작 씬·게임 진행 상태·TimeScale을 복원합니다. 실행 중 스크립트를 다시 컴파일하면 테스트를 종료하므로, 컴파일 완료 후 창에서 다시 시작합니다.

Test Runner의 EditMode에서 `GimmickPlayTestEnvironmentTests`로 간단 테스트의 자동 선택·네 기믹 연속 실행·중단 시 나머지 차단, CSV의 다섯 기믹 포함, 전체 제조의 시계·단계 순서·정량 추가 기록·중단 정리, 반복 시 준비 초기화, 실제 Play 프리팹 연결을 확인할 수 있습니다. 서비스 격리는 공통 구현을 쓰는 `HomeInteractionTestEnvironmentTests.TestServicesReplaceExistingSingletonsWithoutRegistrationConflicts`에서도 검증합니다.
