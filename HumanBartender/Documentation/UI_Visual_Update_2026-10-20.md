## Unity 에셋·편집 규칙

- 기존 PNG/PSD/글꼴 원본 바이트는 변경하지 않았다. `99.TempResources`를 되살리거나 참조하지 않았다.
- 현재 프로젝트에 없던 타이틀 도시 합성 원본만 웹의 `assets/ui/title/street-full.png`에서 `02.Title/01.Sprites/title_street_full.png`로 바이트 그대로 추가했다. 텍스트/버튼이 구워진 `title_screen.png`는 배경으로 사용하지 않았다.
- 타이틀 5개 텍스처에 전체 영역용 `__UIFull` 슬라이스를 추가했다. 원래 GUID, 기존 6개 슬라이스의 spriteID·fileID·영역·피벗을 보존했다. Single로 강제 변환하지 않았다.
- 배치·스프라이트·글꼴·연결 값은 씬/프리팹에 저장했다. 플레이 시작 때 UI 계층을 다시 만드는 방식이 아니다. 새 런타임 컴포넌트의 참조도 Inspector에서 편집할 수 있다.
- 공용 설정은 `ProjectLifeScope.prefab`, 타이틀은 `Main.unity`, 바 대사/선택지는 기존 프리팹과 `Play.unity`에서 조정한다. MonoBehaviour 파일명과 클래스명, Editor/런타임 코드 분리를 유지하고 새 파일마다 `.meta`를 포함했다.
- 기존 카메라의 뷰포트·Input Actions·VContainer 등록·씬 목록·패키지 설정은 바꾸지 않았다. 에디터에서 씬을 열 때 PixelPerfectCamera가 계산하는 뷰포트 값이 UI 편집에 섞여 저장되지 않도록 했다.
- `VisualUISetup`은 이번 에셋 갱신에 사용한 일회성 Editor 도구다. 이미 적용된 프로젝트에서는 다시 생성하지 않는다. 이후 수정은 기존 씬/프리팹 Inspector에서 한다.
- 시작 시 이미 수정되어 있던 다른 리소스의 `.meta` 작업을 일괄 되돌리지 않았다.

## 기능 범위와 구분

설정은 현재 Unity가 제공하는 기능을 새 외형에 연결했다. 웹에만 있는 별도 거리 음량·대사 음색 선택·미리 듣기·언어·자동 진행 등을 동작하는 설정처럼 추가하지 않았다. BGM/SE는 즉시 저장하며, 화면 설정은 ‘적용’으로 확정한다. 초기화도 이 구분을 따른다.

외부 상호작용 선택지는 10월 19일 팀원이 만든 조각 UI를 유지한다. 새 `exterior_textbox/GRD_textbox.png`에는 예시 문구가 포함되어 있어 완성 이미지를 그대로 연결하지 않았다. 외부 말풍선의 조각 조립 및 프로필/매출 화면 전체 재설계는 이번 갱신에 포함하지 않았다. 기존 비활성 기능을 활성화하거나 새 기능을 만드는 작업과 리소스 교체를 구분했다.

제조 화면의 동일 픽셀 원본과 이미 이관된 리소스도 경로에 Legacy가 있다는 이유만으로 바꾸지 않았다. 0일차 엘리베이터의 `LogoFade`는 메인 로고 글리치와 별개로 유지했다.

## 이름·여백 및 타이틀 빗물 후속 조정

- 이름이 위 테두리에 붙던 원인은 원본 말풍선 PNG에 포함된 꼬리 영역이었다. 기존 루트 Image/fileID와 입력 영역을 유지하고, 자식 `Frame`에 원본을 표시해 꼬리와 실제 본문 사각형을 분리했다. 이름은 본문 박스 상단에서 22 아래에 놓고, 본문 시작은 56 아래로 내렸다. 줄 간격은 12다.
- 이름 자동 크기 조정을 껐다. 기존 자동 크기 최대 20과 처음 축소한 13 사이인 16으로 최종 조정했다. 모든 대화창 이름은 `#8FDCFF`를 사용하며, CSV의 기존 화자별 색상 필드는 데이터 호환성을 위해 유지한다.
- `Main.unity`의 도시·암부만 `Canvas_TitleBackground` 카메라 캔버스에 배치했다. 기존 메인 카메라에 `WindowRainLayer`를 연결해 빗물을 합성하며, 로고와 메뉴는 기존 Overlay 캔버스에서 표시한다. 런타임 UI 재생성은 없다.
- 파티클이 없는 타이틀에만 `ambientRain`을 켰다. 기본값은 꺼짐이며, 기존 외부 씬은 계속 실제 비 파티클의 방출 상태를 따른다. 기존 셰이더·렌더러 피처·방울 시뮬레이션을 재사용한다.
- 별도 복제 프로젝트에서 대화·입력·글리치·빗물 회귀 검사 79개가 통과했다. 최종 이름 크기 16으로 변경한 뒤 실제 대사 재생 3개 사례(손님 한 줄/여러 줄, 플레이어)를 다시 검사했다. 실제 TMP 글자와 위 테두리·이름/본문·하단 사이의 여백도 확인했다.
- 실제 Play Mode에서 타이틀의 젖은 배경/마른 배경 픽셀 차이와 빗물 리소스 해제·재등록을 검사했다. 열려 있는 원본 Unity 에디터를 종료하거나 원본 프로젝트에 중복 batch 실행을 하지 않았다.

## 프레임 변형·선택지 정렬·남은 글꼴 조정

- 말풍선 PNG 전체를 사각형에 맞춰 늘리던 표시를 `DialogueFrameMesh`로 바꿨다. 원본의 둥근 모서리와 중앙 꼬리는 가로·세로에 같은 배율을 쓰고 크기를 고정한다. 직선 구간과 본문만 확장한다. 이름 크기 16, 하늘색 및 기존 본문 여백은 유지한다.
- 선택지 A/B 원본의 슬라이스 영역이 서로 달랐다. `ChoiceFrameMesh`가 두 PNG의 실제 공통 테두리 좌표를 같은 버튼 영역에 맞추며, 글로우 여백은 바깥에 표시한다. Unity의 Max Size 축소와 스프라이트 투명 여백도 반영한다. 버튼 클릭 영역·홀드 시간·진행바 연결은 유지한다.
- 선택지 글자의 위/아래 인셋을 4/4로 맞추고 실제 글자 영역을 기준으로 가운데 정렬한다. Play 씬의 네 선택지에 남아 있던 NeoDunggeunmo 폰트·머티리얼 오버라이드를 제거했다. Stardust Regular와 그 폰트의 머티리얼을 함께 연결했다. 기본 글자는 밝은 회색, 포커스 글자는 청록색이며 글리치는 홀드 중에만 재생한다.
- 튜토리얼·코스터·레시피·제조·외부 안내 및 공용 UI에 남은 예전 글꼴을 정리했다. 대사/선택지/이름은 Stardust Regular/Bold, 일반 UI 안내는 Paperlogy Medium/Bold 역할을 따른다. 기존 Text 컴포넌트는 같은 최신 원본 TTF로 연결해 코드의 Text 참조를 유지했다. 월드 TMP의 MeshRenderer 머티리얼까지 새 폰트와 맞췄다.
- 글꼴만 바꾸는 23개 프리팹은 원래 계층과 모든 직렬화 오브젝트 ID를 유지했다. Editor에서 프리팹을 열며 자동 생성되거나 정규화된 다른 UI 변경은 포함하지 않았다. 기존 제작 도구의 기본 글꼴 경로도 최신 글꼴로 바꿨다.
- 튜토리얼 드래그 화살표는 공급 UI에서 실제 드롭 영역 중앙으로 향한다. 좌/우 고정 좌표를 제거하고 회전된 RectTransform의 네 모서리도 화면 좌표로 투영한다. 좌석 상태 설명의 본문도 안내 본문 글꼴을 사용한다.
- 원본 PNG/PSD 및 해당 `.meta`는 이번 프레임·정렬 수정에서 변경하지 않았다. 기존 스프라이트 GUID/슬라이스를 사용하고, 새 UI 메시 컴포넌트를 프리팹에 저장했다.
- 복제 프로젝트의 대화·선택지·정렬·글꼴 검사 41개가 통과했고, 마지막 포커스 글자 색 보정 뒤 관련 26개를 다시 실행해 통과했다. 최소/최대 말풍선의 모서리/꼬리 배율, 실제 선택지 네 칸의 한 줄/두 줄 중앙 정렬, A/B 테두리 위치, 이동·회전 후 화살표 도착점, 전체 게임 씬/프리팹의 예전 글꼴 참조 부재를 검사했다.
- 실제 Main → Play 새 게임 튜토리얼을 진행하는 검사도 통과했다. 코스터 단계에서 화살촉이 실제 드롭 영역 중앙에 있는지 확인하고, 마우스로 코스터를 드래그해 튜토리얼 완료·제조 준비까지 진행했다. 검수 화면과 결과는 `ui-review-2026-10-20/frame-alignment-and-fonts/`에 보관했다.
