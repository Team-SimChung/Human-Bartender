# 따르기 고정 목표 높이 가이드

기준: 2026-11-05, Unity 6000.3.14f1. Pour와 FillUp의 `NewPourGame.prefab`에 적용한다.

## 수정한 문제

360ml 목표에 363.39ml가 담긴 화면에서 액체 본체가 고정 목표선보다 확연히 높았다. 목표선을 움직이지 않게 하는 검사만으로는 높이 정확도를 보장할 수 없었다. 이전 단순 용량 비율식은 SPH가 실제로 쌓인 높이를 충분히 반영하지 못했다.

실시간 보정은 계속 꺼둔다. 대신 실제 병에서 액체를 흘려 담은 결과로 미리 측정한 고정 환산 곡선을 사용한다.

## 현재 계산

```text
목표 비율 = 목표 입자 수 × 입자당 ml / 표시 용량
높이 비율 = LiquidProfile.targetHeightByFillRatio.Evaluate(목표 비율)
고정 목표선 = 잔 바닥 + 잔 내부 높이 × 높이 비율
```

기믹 시작 시 한 번만 계산한다. 액체가 들어오거나 넘치거나 잔이 비어도 선은 움직이지 않는다. 실행 중 수면 측정이나 GPU 읽기를 추가하지 않았다. 실측 곡선은 `Liquid_Light.asset`에 저장돼 있으며, 빈 곡선은 기존 용량 비율로 계산한다.

목표 단위가 oz이면 기존 balance 데이터의 환산 계수를 사용한다. `weizen`은 450ml, 일반 잔은 300ml를 사용한다. 정답이 숨겨진 재료는 높이 가이드도 숨긴다. 계산 높이가 잔을 벗어나면 잔의 내부 범위로 제한한다.

수량은 바닥이나 이미 담긴 액체에 도착한 입자 수로 계산하고, 넘쳐 나간 입자는 뺀다. 이 계산 방식과 레시피 판정은 바꾸지 않았다.

## 사전 측정

현재 Light 설정과 기본 잔 내부 1.3×2.54에서 다음 실제 경로를 사용했다.

```text
PourManager.CreatePool / CalibrateRestDensity
 → BottleTiltController의 실제 병 입구 위치와 140도 기울기
 → EmitFromNeck / EmitRow (95도 시작, 110도 최대 유량, 70ml/s × 0.25)
 → SphSimulation.Tick (120Hz)
 → SphVolumeTracker의 실제 도착량 (60Hz)
 → 출수 중단 후 안정화
 → 실제 D3D11 액체 셰이더의 본체 수면 측정
```

격자에 목표 입자를 미리 넣어 놓은 결과만 사용하지 않았다. 일반 병 출수·충돌·도착량을 거쳤다. 곡선의 X는 요청량 대신 최종 도착량으로 기록하여 방출 행의 입자 단위 반올림도 반영했다. 0부터 90%까지 12개 출수량을 측정하고, 잔이 비어 있는 점과 상단 외삽점을 포함한 14개 키를 선형 보간한다. 거품 높이는 기준에 포함하지 않는다.

기존 단순 비율식에서 맥주 360ml의 고정선은 잔 로컬 Y=0.762였다. 수정 후 Y=0.86317로, 약 0.10117 월드 단위 높아진다(기본 스케일 1). 한 가지 오프셋을 모든 양에 더하는 방식이 아니므로 소량과 많은 양의 서로 다른 오차를 함께 반영한다.

## 검증

사전 측정과 다른 난수 시드로 다시 실제 병에서 흘려 담고, 최종 수량과 셰이더 수면을 비교했다. 높이는 잔 로컬 좌표다.

| 목표 | 잔 스케일 X/Y | 고정 목표선 | 실제 액체 본체 수면 | 오차 |
| --- | --- | ---: | ---: | ---: |
| 30ml | 1 / 1 | -1.02308 | -1.04180 | 0.01872 |
| 90ml | 1 / 1 | -0.48879 | -0.48617 | 0.00262 |
| 12oz = 360ml | 1 / 1 | 0.86317 | 0.86320 | 0.00003 |
| 90ml | 1.6 / 0.85 | -0.48879 | -0.48617 | 0.00262 |

붓는 도중 360ml에 도달하는 순간도 별도로 측정했다. 목표선 Y=0.86317, 액체 본체 Y=0.90289, 오차 0.03972로 입자 한 간격(0.065)보다 작았다. 흐르는 중에는 물결·유입 때문에 안정된 수면보다 높을 수 있다. 목표를 3.39ml 초과한 경우에도 본체가 목표선보다 조금 높아지는 것은 정상이다.

실제 출수 후 일치·출수 중 목표 도달·매 측정 시점의 목표선 고정·oz/ml 환산·잔 스케일·목표 숨김·초과량·빈 잔 및 기존 도착량/종료 검사 등 **31개 통과, 실패 0개**. 전체 런타임·에디터 C# 컴파일도 통과했다. 사용 중인 원본 씬을 전환하거나 저장하지 않고 별도 검증 프로젝트에서 실행했다. 전체 게임 수동 플레이나 FPS 개선을 검증한 결과는 아니다.

Light 물성이나 입자 간격·잔 형태를 크게 바꾸면 사전 측정 곡선도 다시 확인해야 한다. 현재 게임이 사용하는 Light 설정을 측정했으며, 다른 물리 프로파일에 Light의 곡선을 강제로 적용하지 않는다.
