# 바 내부 대사 테스트

Unity 메뉴 **Tools > Human Bartender > Tests > Bar Dialogue Lab**에서 엽니다. 홈·외부 상호작용 창과 기믹 테스트 창에서도 **바 내부 · 대사를 골라 시작**으로 열 수 있습니다.

## 대사를 골라 시작

1. 작업 중인 씬을 저장하고 Play 모드를 종료합니다.
2. **대사 일차**에서 0~3일차를 고릅니다.
3. **대사 검색 (본문 / 인물 / ID)**으로 찾습니다. **개점 대사 / 2부 대사**로 좁힐 수도 있습니다.
4. 실제 대사 목록에서 시작할 한 줄을 클릭합니다. 대사 전문, 인물, 원래 조건, 씬·스텝 번호가 아래에 표시됩니다. 주문 문구도 선택할 수 있습니다.
5. 앞 서빙 이후 분기를 확인하는 경우 **생략한 앞 서빙의 등급 / 주문 일치**를 고릅니다.
6. **선택 대사부터 테스트 시작**을 누릅니다. 실제 Main 부트스트랩과 Play 씬을 사용하고, 1부 영업·앞 대사·앞 컷씬을 생략합니다.
7. Game 창에서 대사·선택·제조·서빙을 진행합니다. 창의 **대사 진행**, **대사 테스트 중단**도 사용할 수 있습니다.
8. 다른 줄을 고른 뒤 **조건 초기화 후 선택 대사부터 다시**로 반복합니다. 앞 실행의 효과가 누적되지 않도록 플레이어와 씬을 다시 준비합니다.

홈·외부·바 테스트는 한 격리 세션을 공유합니다. 별도 Play 세션과 동시에 시작할 수 없습니다. 원본 플레이어와 기존 저장은 사용하지 않으며 종료 시 원래 시작 씬·게임 상태·시간 배율을 복원합니다.

## 시작 상태

선택한 국면의 앞 자동 대본과 현재 대본의 앞 단계를 읽어 좌석·인물, 미완료 주문, 스텝 효과를 준비합니다. 2부에서 시작하면 개점 대본의 스텝 효과도 반영하되 개점 종료 시 좌석·주문·서빙 문맥을 비우는 실제 흐름을 따릅니다. 인물은 처음부터 앉은 상태로 배치하고 앞 대사·컷씬·튜토리얼 조작은 출력하지 않습니다.

건너뛴 앞 서빙은 선택한 등급·주문 일치로 분기 문맥만 준비합니다. 실물 잔·제조 기록·서빙 정산 수입을 생성하지 않습니다. 미완료 자유 주문은 해당 일차에 사용할 수 있는 첫 확정 레시피를 자동 선택합니다. 이후 실제 주문·제조·서빙은 원래 실행기와 실제 결과를 사용합니다.

앞 선택지는 자동 선택하지 않으므로 선택 항목의 효과까지 복원하지 않습니다. 선택한 첫 대사는 표시하며 그 이후 단계·선택지의 조건과 효과는 그대로 평가합니다. 원래 조건을 만족하는 연속 분기를 보려면 표시된 조건에 맞는 서빙 등급 등을 선택합니다.

3일차 테스트는 실제 진입에 필요한 와일드 독·비터스·기억 조건을 준비합니다. 각설탕 수령과 조니 레시피 해금은 앞 대본 단계의 효과와 기존 해금 규칙을 따릅니다.

대사가 끝나면 해당 국면의 뒤 자동 대본까지 이어 가고, 정산 화면·퇴근·날짜 진행은 자동 실행하지 않습니다. 정상 영업 전체의 진행은 실제 게임 시작으로 확인합니다.

`BarDialogueTestEnvironmentTests`는 실제 날짜별 대사 목록의 누락·중복, 시작점 준비에서의 좌석·효과·미완료 주문·서빙 결과, 원본 대본 보존을 검증합니다.
