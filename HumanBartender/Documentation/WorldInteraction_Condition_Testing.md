# 월드 상호작용 조건 테스트

Unity 메뉴 **Tools → Human Bartender → Tests → Game Interaction Lab**에서 사용합니다.

1. 시작 씬을 Home 또는 OutSide로 선택합니다.
2. **조건별 상황 준비**에서 조건 종류와 상황을 고릅니다. 적용할 돈·플래그도 펼쳐 볼 수 있습니다.
3. **이 상황으로 테스트 시작**을 누릅니다. 실행 중에는 **상황 다시 준비**로 날짜·국면·위치와 격리 진행을 초기화합니다.
4. 현재 씬·일차·국면이 같은 경우 **조건만 적용**으로 표시된 돈·플래그만 바꿉니다. 다른 진행 기록·호감도는 유지합니다.
5. 각 대상의 **관련 조건 준비 선택**으로 해당 대상의 준비 목록을 찾습니다. 기존 수동 돈·플래그 수정도 사용할 수 있습니다.

## 준비하는 상황

| 종류 | 주요 상황 |
|---|---|
| 부비 | 박스 발견 전후, 참치캔 보유/미보유, 먹이 진행 중, 입양 후 외부 숨김, 홈 쓰다듬기, 첫 취침 |
| 상점 | 첫 방문/재방문, 49원/50원 경계, 구매 완료, 용돈 미수령/수령, 교육 준비/완료 |
| 수리·엘리베이터 | 부품 보유, 현금 399원/400원 경계, 지불 완료, 수리 완료·수리공 퇴장, 탑승 |
| 경비·보스 | 통행 허가 전후, 현금 499원/500원 경계, 수리 보상, 거래 확정 후 수령 전, 수령 완료 |
| 불량배·정보 | 첫 조우/재회, 지불 부족/기지불, 정보 구매 49원/50원 경계 |
| TV | 0~3일차 전원·메뉴, 시청 전후, 1일차 주변 방송 |
| 취침·엔딩 | 작업장·테라스, 취침 조건 부족/충족, 부비 첫 휴식, 삼호 생존/사망 엔딩 |
| 집 안 조사·거리 | 현관·바·집 문, 침대·옷장·책, 삼호·밀수업자·계약 종료, 수배 전단 |

같은 계열의 준비 상황을 바꾸면 해당 계열의 구매·완료 플래그도 명시적으로 해제합니다. 예를 들어 참치캔 보유 상황에서 미보유 상황으로 바꾸면 소유 플래그를 false로 되돌립니다.

게임의 실제 CSV·사건 처리기를 사용하며 아이템도 실제 소유 플래그로 준비합니다. 상호작용 실행 중에는 조건 변경을 막습니다. 기존 플레이어와 저장 파일은 Home Interaction Lab의 격리 세션으로 보호합니다.

## 현재 캠페인에서 닫힌 대상

구형 bubi Source의 `day > 3 && day == 2`는 충족 불가능합니다. 구형 shiba·일부 포스터는 `day > 3`이라 현재 0~3일차 범위에서 닫혀 있습니다. 창에 사유와 대체 NPC 지점을 표시합니다.

실제 배치된 Home·OutSide 지점을 기준으로 준비 목록 또는 닫힌 사유를 검사합니다. 임의의 모든 플래그 조합을 생성하지 않으며, 현재 씬에 없는 QA 99일차 대상을 추가하지 않습니다.

## 자동 검증

EditMode Test Runner의 `WorldInteractionPreparationTests`, `WorldInteractionTestEnvironmentTests`, `HomeInteractionTestEnvironmentTests`를 실행합니다.

- 모든 배치 지점의 준비 목록·닫힌 조건 누락 검사
- 각 준비 상황의 실제 CSV·네이티브 등장 조건 검사
- 실제 부비·수리·보스·상점 선택지의 활성/비활성 검사
- 상점의 용돈·교육 선행 분기 검사
- 조건 적용의 기존 진행 유지와 전체 초기화 동작 검사

Game 창에서의 이동·연출·선택 조작은 각 상황의 설명대로 수동 확인합니다.
