# 제작 원본

`02.Working`에는 현재 Unity 자산의 의존성에서 참조되지 않는 PSD, Aseprite, Spine, CLIP 원본을 분류했다. 원래 `.meta`도 복구를 위해 함께 보존했다. 이 위치는 Unity의 Assets 밖이므로 게임에서 직접 로드되지 않는다.

Google Drive 최신 묶음 중 게임에 연결된 이미지는 `Assets/01.Game/03.Content`, 미적용 리소스는 `Assets/02.ArtStaging/01.GoogleDrive`에서 관리한다. 전체 묶음을 이 폴더로 옮긴 것이 아니다.

원본 경로와 현재 경로는 [이동 대응표](../03.Documentation/04.AssetMigration/20260929/file-map.csv), 전체 변경 전 백업 위치는 [복구 자료](../03.Documentation/04.AssetMigration/20260929/README.md)에 있다.
