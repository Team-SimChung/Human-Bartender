# 칵테일·레시피·재료

칵테일 이름과 가격은 cocktails.csv, 제조 동작과 수량은 recipes.csv, 재료·도구는 shelf_items.csv에서 설정합니다.

| CSV 파일 | 엑셀 시트 | 설정하는 내용 |
|---|---|---|
| `cocktails.csv` | Cocktails | 칵테일 이름·가격·도수·제조 조건 |
| `cocktail_tags.csv` | CocktailTags | 칵테일별 맛·느낌 태그 |
| `recipes.csv` | Recipes | 칵테일별 제조 동작·재료·수량·필수 재료 여부 |
| `order_rules.csv` | OrderRules | 주문 결과 판정 조건과 효과 |
| `shelf_items.csv` | ShelfItems | 재료·도구·진열·해금 설정 |
| `tastes.csv` | Tastes | 캐릭터별 술 취향 조건과 우선순위 |
