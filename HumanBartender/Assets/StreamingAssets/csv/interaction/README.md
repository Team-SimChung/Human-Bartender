# 거리·집 상호작용

interact_points.csv는 등장 조건과 행동, dialogue_flows.csv는 연결할 대화와 반복 여부를 설정합니다. 실제 위치는 Unity 씬에서 편집합니다.

| CSV 파일 | 엑셀 시트 | 설정하는 내용 |
|---|---|---|
| `interact_points.csv` | InteractPoints | 상호작용 대상·장소·등장 조건·행동 |
| `dialogue_flows.csv` | DialogueFlows | 상호작용별 대화 장면·날짜·선택 순서·반복 여부 |
| `spots.csv` | Spots | 장소 ID와 설명. 좌표는 Unity 씬에서 편집 |
