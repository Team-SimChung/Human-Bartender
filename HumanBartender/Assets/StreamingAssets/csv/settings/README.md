# 날짜·밸런스·UI·전환

시작 금액 등은 balance_config.csv의 setting/value, 날짜별 설정은 days.csv, UI 문구는 ui_strings.csv에서 수정합니다.

| CSV 파일 | 엑셀 시트 | 설정하는 내용 |
|---|---|---|
| `balance_config.csv` | BalanceConfig | 전역 밸런스 키와 값. value_type에 맞춰 편집 |
| `grade_cuts.csv` | GradeCuts | 등급별 점수 경계 |
| `settlement_rules.csv` | SettlementRules | 정산 규칙 키와 값 |
| `score_bands.csv` | ScoreBands | 점수 구간별 보상 배율 |
| `affinity_matrix.csv` | AffinityMatrix | 취향·등급에 따른 호감도 변화 |
| `days.csv` | Days | 날짜별 시작 단계·배경음·유지비 |
| `endings.csv` | Endings | 엔딩 선택 조건과 장면 ID |
| `text_tags.csv` | TextTags | 대사 태그의 색상·속도·크기 |
| `transitions.csv` | Transitions | 장소 이동 ID·목적지·연출 |
| `ui_strings.csv` | UIStrings | UI 문구의 한국어·영어 |
