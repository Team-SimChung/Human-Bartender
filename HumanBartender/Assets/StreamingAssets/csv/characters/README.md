# 캐릭터·표정·동작

이름과 역할은 characters.csv, 표정 리소스는 expressions.csv와 expression_parts.csv에서 설정합니다.

| CSV 파일 | 엑셀 시트 | 설정하는 내용 |
|---|---|---|
| `animation_characters.csv` | AnimationCharacters | 표정 사전의 캐릭터 키 |
| `expressions.csv` | Expressions | 표정 이름·표시 방식·이미지·말하기 애니메이션 |
| `expression_parts.csv` | ExpressionParts | 표정별 눈·입·몸 등 부위의 클립과 반복 설정 |
| `characters.csv` | Characters | 캐릭터 이름·색상·역할·기본 외형 |
| `character_expressions.csv` | CharacterExpressions | 캐릭터가 사용할 수 있는 표정 목록 |
| `dossier.csv` | Dossier | 캐릭터 정보 공개 조건과 문구 |
| `field_animations.csv` | FieldAnimations | 필드 캐릭터 동작과 리소스 |
