# 표 연결·형식 규칙

일반 콘텐츠 편집 때는 그대로 유지합니다. balance_root.csv는 밸런스 하위 표를 연결하는 부모 행이며 게임 설정값을 편집하는 표가 아닙니다.

| CSV 파일 | 엑셀 시트 | 설정하는 내용 |
|---|---|---|
| `balance_root.csv` | 편집 대상 아님 | 밸런스 하위 표를 연결하는 고정 부모 행: balance_root |
| `table_index.csv` | 편집 대상 아님 | 표 이름·상대 파일 경로·편집 여부 |
| `columns.csv` | 편집 대상 아님 | 열 순서와 값 타입 |
| `data_sets.csv` | 편집 대상 아님 | 데이터 묶음의 루트 연결·원본 출처 체크섬 |
| `row_formats.csv` | 편집 대상 아님 | 중첩 필드·목록·사전의 연결 규칙 |

새 필드나 새 데이터 묶음을 추가할 때만 코드와 함께 규칙을 확장합니다. 일반 대사·수치 편집에는 필요하지 않습니다.
